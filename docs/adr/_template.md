# NNNN. Title in the imperative

**Status:** Accepted | Superseded by [NNNN](NNNN-slug.md)
**Date:** YYYY-MM-DD

## Context

What forced a decision. The constraint, the conflict, or the thing that kept going wrong. Enough
that someone who was not there can tell whether the reasoning still applies.

## Decision

What was chosen, stated plainly.

## Consequences

What this costs, not only what it buys. Name the cases where the decision is inconvenient — those
are what a future reader needs, because the upside is usually obvious from the code and the
downside never is.

## Alternatives considered

Each with the reason it lost. An alternative with no stated reason reads as an oversight and
invites someone to "improve" the decision by reversing it.
